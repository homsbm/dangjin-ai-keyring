NFC Tools 앱 활용 가이드

스마트폰 웹 브라우저에서 직접 NFC를 쓸 수 없거나 아이폰일 경우:

  1. 스마트폰 앱스토어에서 'NFC Tools' 앱을 다운로드합니다.
  2. 상단 메뉴에서 [쓰기 (Write)] 탭을 클릭합니다.
  3. [레코드 추가 (Add a record)] → [URL / URI] 선택 후 복사한 URL 입력.
  4. [쓰기 (Write)] 버튼을 누르고 NFC 키링을 스마트폰 뒷면에 대어 완료합니다!
